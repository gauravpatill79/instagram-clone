#Pin Saved Reels Feature for Instagram.

A user-friendly feature that allows users to save and pin reels, similar to Instagram's pinned content experience.

#Functionality:

1.Users can save reels to their personal collection.

2.Users can pin up to 3 reels in their "Saved Reels" section.

3.Attempting to pin a 4th reel prompts the user to unpin an existing reel first.

4.Pinned reels appear at the top of the saved section for quick access.

Tech Stack Used:
1.ReactJs,Chakra UI, Zustand and Firebase.
